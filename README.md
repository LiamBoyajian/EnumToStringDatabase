A small class to interact with an enum to string database; intended for a Godot environment. 

Implements commands like Get, Put, Remove, Update to make changes to the database. 

Designed to allow an enum to store references to many file paths (strings), while distinguishing between copies with an int (key). Tests for the implementation are also provided. 



I am not planning to update outside my Godot project needing it.


Ai was used only to learn sql and c#-testing, and was never used to create any code.
